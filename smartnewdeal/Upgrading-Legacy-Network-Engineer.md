When UnitedwithCode co-founder Bruce Caslow wrote his CCIE Lab preparation textbook *Cisco Certification Bridges, Routers and Switches* (Prentice Hall, 840 pages) in 1998, the primary tool of a network engineer was terminal software such as Putty or SecureCRT, supplemented with spreadsheets, Visio, SNMP network management, packet decoders, and automation via TCL, Perl and Expect. Terminal software and the CLI ruled supreme.

**From CLI to API!** Over the last 20 years, virtualization, cloud services, software defined networking, infrastructure as code, network automation, zero trust networking/SASE and machine learning have changed how a network engineer works. It is time for all network engineers to consider leading with some form of automation tool and following with terminal software.

### A Major Paradigm Shift In the Standard Network Engineering Tool Kit
We no longer lead with terminal/CLI access followed by other tools. We now lead with automation software and follow with terminal/CLI access. Network engineers must be prepared to play the role of subject matter expert (SME) to help guide network automation and integrate networking data with Cyber Security, Data Analytics/Data Science, DevOps, Cloud, and ticketing/chatops teams.

### UnitedwithCode's Four Tracks to Upgrade a Legacy Network Engineer Skill Set
- **Track #1 — 100% Open Source Track:** Deploy open-source python-centric tools such as Ansible, NAPALM, Nornir on your own. Requires a high degree of Python literacy. No software licenses needed.
- **Track #2 — 100% Open Source with a Support Contract from a Consulting Partner:** Take the open-source route but partner with a consulting firm for support (as with SNORT, NESSUS, Elastic). No software licenses needed.
- **Track #3 — Hybrid Open Source/Proprietary Software Tools Track:** Purchase licenses for proprietary tools but get full vendor support. Two of Bruce Caslow's former CCIE students launched companies with robust automation platforms using SSH/SNMP; UnitedwithCode recommends a specific proprietary platform per student.
- **Track #4 — The Virtual Network/Public Cloud Training Track:** Supplement legacy networking skills with virtualized network services using VMWare NSX and public cloud (AWS, Microsoft Azure), and learn to integrate these with legacy enterprise networks.

### Signature Teaching Techniques
Rigorous hands-on training: Spot the Issues (build mental decision trees), Options Analysis (never memorize a solution), Step-by-Step Problem Penetration (break complex problems into ordered sub-problems). Make theory come to life with Proof by Debug, Proof by Wireshark, Proof by Python, and more.
