UnitedwithCode offers two training courses: (1) Upgrading the Legacy Network Engineer Skill Set in an Evolving World of Infrastructure as Code, and (2) Hands-on Data Science Training. The second course teaches Data Science skills to apply in a world of "healthcare infrastructure as code," "finance/blockchain/fintech infrastructure as code," and many more domain-specific implementations. Regardless of the implementation, data is generated and can be analyzed — this is where Data Science becomes prominent. The killer app of Data Science is Machine Learning.

The course teaches a skill set applicable to: Network Engineering, Cyber Security, IT in general, HealthCare, Investing, Sports Betting, Climate Science, Social Justice/Governing — the applications are infinite.

### The Data Science Skill Set Venn Diagram
Data Science involves three skill sets: (1) Computer Science skills, (2) Math and Statistics skills, (3) Domain Knowledge of a specific field.

Key Python Data Science modules used: **numpy**, the **Berkeley Data Science Module**, **PANDAS**, **matplotlib**, and more. The course builds a baseline of hands-on literacy; advanced Data Science requires mastering calculus, linear algebra, measure theory, and advanced probability and statistics. "Data Science is more about math than it is about computer science."

### Course Outline
**Part One: Python Fundamentals** — Lesson 1: Getting Started with Python (Object Names, Types, Attributes); Lesson 2: Basic Python Data Types (string, integer, float, list); Lesson 3: Python Built-in Functions; Lesson 4: Using Square Brackets with Strings and Lists; Lesson 5: Exploring Python Tables (a two-dimensional data structure); Lesson 6: Understanding Python Error Messages; Lesson 7-A: Vocabulary of Python Keywords; Lesson 7-B: Importing Python Modules and the dot notation; Lesson 8: Introducing PANDAS and the Python Dictionary.

**Part Two: Python Mathematics Modules** — Lesson 1: Simultaneous Equations with SymPy; Lesson 2: Binary Trees and Recursion for Deductive Math; Lesson 3: Combinatorics and the Python itertools module; Lesson 4: Case Study — Analyzing Bank Statements and Purchasing Patterns.

**Part Three: Learning Probability and Statistics with Python** (same topics as a college Intro to Statistics or AP Statistics course, taught with numpy, pandas & the Berkeley Data Science Module) — Lesson 1: One-Variable Data Analysis; Lesson 2: Two-Variable Data Analysis; Lesson 2-A: Case Study — Analyzing Heart Rate Data from an Apple Watch; Lesson 3: Fundamentals of Probability; Lesson 4: Distribution Types, Sampling Distributions and Bootstrapping; Lesson 5: Inference — Estimating and Confidence Intervals; Lesson 6: Inference — Testing Hypotheses; Lesson 7: Inference for Regression; Lesson 8: Case Study — Using Data Science to Promote Social Justice.
