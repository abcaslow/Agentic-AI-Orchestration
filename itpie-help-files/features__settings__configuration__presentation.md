[ITPIE:OPS Documentation | Presentation | https://itpie-hostname/documentation/content/features/settings/configuration/presentation.html] It is impossible to know for certain when a device has been removed from the network, since failure to contact the device on any particular collection could be the result of a temporary network failure. ITPIE therefore has the concept of an age-out period. If it has not collected on a device within a certain number of days, it will assume that the device has been removed and it will no longer show up in searches or other pages in ITPIE. (It is not removed from the database, however, and can still appear in things like the Maps' component history feature.)
[ITPIE:OPS Documentation | Presentation | https://itpie-hostname/documentation/content/features/settings/configuration/presentation.html] This setting is configurable on this page.
[ITPIE:OPS Documentation | Presentation | https://itpie-hostname/documentation/content/features/settings/configuration/presentation.html] Device Age-Out Period: The number of days before a device that has not been collected on will be considered no longer on the network. Defaults to 7.
