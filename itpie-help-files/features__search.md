[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Reduces Mean Time to Secure (MTTS)
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] If synchronization on the Network Time Protocol (NTP) is lost, the ability to correlate logs on security events could be destroyed. If the Terminal Access Controller Access Control System (TACACS) is misconfigured and static local accounts are being used instead could cause issues with correlating the security event logs. ITPIE Search provides the configuration state of the network to help resolve these issues.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Enhances Security
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] A Cyber OPS user is provided an IP or MAC address and told to find its location on the network. Utilizing ITPIE OPS Search, the user has the ability to enter the IP or MAC address and ITPIE relays back location specific information such as switch location and port location that could be used to identify where the device is located.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Provides Quick Problem Resolution
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The Intelligent Search feature functionality assists with finding problems on the network so that the Network Engineer is able to resolve any problems or issues.

[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The Intelligent Search CLI
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] ITPIE's Intelligent Search feature behaves differently than most web search features. It was designed to mimic the way a Network Engineer would use a network device's command line interface. Here are a few things you should know about the syntax.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The CLI forms queries following the basic pattern below.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] <verb> <subject> <query> <option> <option-query>
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Verbs
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Currently ITPIE supports the find verb, which is aliased to show . Either command will work the same.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Subjects
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] ITPIE supports a growing list of <subjects> that can be queried on. See the expanded Command Reference below for a full list.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Subjects can be shortened in many cases and will respond to abbreviated versions. For example, find device can be shortened to find de .
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Queries
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The ITPIE CLI will allow the use of wildcards in a query. We use the * character as the wildcard, so the command find device c3560* will return all the devices with a hostname that begins with c3560 .
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Options
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The ITPIE CLI supports a numbr of command specific options that modify the type of output returned by the query. See the Command Reference for a full list of supported options for each command. Some options may also allow additional query parameters.

[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Select the command and enter the options as needed.
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] Press Enter or click Search .
[ITPIE:OPS Documentation | Intelligent Search | https://itpie-hostname/documentation/content/features/search.html] The command is run and the results are displayed.
