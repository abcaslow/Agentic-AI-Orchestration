[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Summary
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Export is a feature that we can use to share data collected in ITPIE with any external sources. Currently it supports pushing data to ServiceNow's CMDB . A scheduler is available to create tasks which push data to external sources that can be executed automatically or manually.

[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Getting Started
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] The first step is to define the target service that we're exporting to.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Go to the export target list page, click "Add Target" button. Enter a name, the endpoint url, and the login credentials.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Note
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] If you have used a version of the Export feature prior to the July 2024 release of ITPIE, you may see a "Migrate" button on this page. If you do, please click the button to update your credential storage to the new system. After your system has been updated, the button will disappear.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Once you have saved the target, the job items and schedules tab will be enabled. This will allow you to start creating job items by clicking the "Add Job Item" button.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] On the "Create Job Item" page, select the source of data to export. The sources available are the same sources used in ITPIE custom reports . Next, select the target table in ServiceNow. The target dropdown will show a hierarchical list, the way ServiceNow tables are organized. As you expand a level, its child tables will appear under it. When you have found the table you want, click on it to select and close the list. This is done by selecting the names for "Source Table" and "Target Table" dropdowns.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] After you have selected the target table, the fields in the table will appear on the right hand side. Next to each target field, to its left, is a dropdown containing all the fields available in the source table. You can select a matching field from the source table that you want to populate the corresponding field in the target table. You can select as few or as many fields as you want to export, but you must select a matching field where the ServiceNow field is required.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Note
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Note that ServiceNow fields may have some data limitations, such as a maximum length. ITPIE will try to export the fields just as they are. ServiceNow will try to coerce the data into the right format; for example, if the data is too long, it will truncate it so it fits. Some ServiceNow fields only accept values from a specific list, and will reject any values not in that list. The export process does not get any feedback when fields are modified or left out in this way.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Next to each set of fields, to the left, is a checkbox indicating that the field marks the record as unique. When exporting data, ITPIE will first pull existing data from ServiceNow and compare each record with data in the source table. If the records marked as "unique" match in both the ITPIE source and the ServiceNow target, ITPIE will assume that records are the same and it will not try to export a new row in the ServiceNow table. Instead, it will update the existing row with other fields in the ITPIE source table.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Warning
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] This is an important part of the export process. You should always select one or more fields as "unique" in any job item that you create. Otherwise, every time the export is run, you will insert all records from ITPIE into ServiceNow, which is almost certainly not what you want.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] Once Job Items are created, you can setup schedule tasks to execute the export. Select the Schedule tab and click the "Add Schedule" button.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] The scheduler works just like other schedules in ITPIE (for example, the one for collections ). You select the schedule that you want to run, and then you choose the job items that you want executed on that schedule. You can also run a schedule manually from the schedule list.
[ITPIE:OPS Documentation | ITPIE Export | https://itpie-hostname/documentation/content/features/export.html] The status page shows which scheduled jobs have run, what time, and how many records were successfully exported (this includes updates as well as insertions).
