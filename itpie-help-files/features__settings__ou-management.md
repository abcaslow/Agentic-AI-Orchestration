[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] OU Management
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Organizational Units ( OUs ) are used to define a folder-like hierarchy you can use to group various subnets and other network data within. It's flexible and hierarchical nature allows for the ability within the system of addressing an entire "branch" of the system (like folders along with their respective sub-folders etc.) or to examine a particular section of data (like a single folder). Each OU can have one or more subnets assigned to it as well as specific users assigned to it.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] A sample OU List where the system is organized by geography. You can organize the system in whatever way best suits your information, this geographic organization is merely a sample.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Creating OUs
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] You can create an OU by clicking the "Create OU" button or by using the menu on an existing OU and selecting a relevant option such as "Create Child OU" which allows you to directly add an OU beneath the respective OU.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Managing OUs
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] By clicking on the menu for a given OU you can edit or delete the OU. Additionally you can move it under a different parent to adjust your structure.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Within each OU you can specify the relevant data for that OU
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Subnets You can specify subnets to define which network data belongs to this OU.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] Users Define which users should have access to this OU and the relevant network data assigned to it.
[ITPIE:OPS Documentation | OU Management | https://itpie-hostname/documentation/content/features/settings/ou-management.html] You can also edit the name or description of the OU.
