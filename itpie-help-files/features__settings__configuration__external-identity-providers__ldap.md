[ITPIE:OPS Documentation | Directory Server (LDAP) | https://itpie-hostname/documentation/content/features/settings/configuration/external-identity-providers/ldap.html] The application may be configured to authenticate with an identity provider that implements the Lightweight Directory Access Protocol (LDAP). These are often referred to as directory servers. Settings may be tested to ensure a good connection before submitting the form. A demo user search may also be performed to confirm search-specific settings, especially attribute mapping.

The 'Base' option searches only the base object. The 'One' option searches only immediate subordinates of the base object. And the 'Sub' option searches the base object and all entries in the subtree of the base object. Defaults to 'Sub'.
