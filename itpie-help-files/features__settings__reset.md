[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] This page allows you to delete all data from one or more schemas in your database. This is not something you would normally ever want to do. It is provided as assistance with setting up your system, when you might want to experiment with some features but then want a clean start when you decide on your final configuration.
[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] The page gives you three options for schemas to reset:
[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] Collection This will remove all of your scheduled collections, including their authorization information, and all data that they have collected -- essentially, all the raw data that ITPIE has gathered
[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] Analysis This will remove all data from Maps, Search, Config Backup, and Discovery. This is all the processed data that ITPIE has analyzed.
[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] Network Data This will remove all records from all Network Data entities. Unlike the other reset options, this option will only remove data that you have added to the system (by manual entry or importing). It will delete all saved data from reports so that they will have to be refreshed before they can be viewed again.
[ITPIE:OPS Documentation | Reset | https://itpie-hostname/documentation/content/features/settings/reset.html] You can choose to reset any or all of these schemas. It is important that you do not reset your data unless you are absolutely sure you know what you are doing; reset data cannot be recovered!
