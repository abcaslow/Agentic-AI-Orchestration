[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] Summary
[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] We've introduced a new, experimental ITPIE chatbot named Theia, backed by an LLM trained on the ITPIE documentation. Among other planned improvements, the scope will expand to incorporate user provided documentation as well as raw collected output and analyzed network data providing a natural language interface to all ITPIE data.
[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] Usage
[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] The "Ask Theia" feature is enabled by authorizing a connection to a machine-learning agent . This action is found on the Collection page under the Agents tab.
[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] Once a machine-learning agent is authorized, a button reading "Ask Theia" will appear at the top of the page next to the "Help" link.
[ITPIE:OPS Documentation | ITPIE Chatbot | https://itpie-hostname/documentation/content/features/chatbot.html] Clicking the "Ask Theia" button opens a drawer on the right where you can ask questions in natural language to get help on how to use ITPIE.
