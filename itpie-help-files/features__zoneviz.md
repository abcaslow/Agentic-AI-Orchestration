[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Summary
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] ZoneViz is a dynamic map presentation tool that provides hierarchical logical views of network enclaves, including traffic flow through security/routing/switching devices and related VLANs. Users input the structure of their network, expressed in worlds, enclaves, network objects, and security zones. A ZoneViz diagram combines network Layer 2 and Layer 3 elements in an easy-to-read format for network engineers. Customers are able to view core devices and enclave specific VLANs that their network traffic will flow through, and use this information, in tandem with “find route” and packet captures, to diagnose where traffic is being blocked or altered.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Definitions
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] World
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] A world is a self-contained network at the highest level of ZoneViz. When you drill down into a ZoneViz diagram, you will see the details of one world at a time
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Enclave
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] A world is composed of one or more enclaves. Enclaves are self-contained, but may have connections to other enclaves or to the outside world (internet). One enclave is designated the "starter." It will appear at the top of the diagram (and the data entry form) for a given world and it will always remain visible. Other enclaves may be expanded, but only one will be visible (besides the starter enclave) at a given time.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Network Object
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] A network object is a network element in an enclave: a firewall, router, load balancer, switch, or other network tool. Network objects are arranged in a specific order and will be laid out in that order, from left to right on the diagram. Users may link network objects to specific devices that ITPIE discovers or to user-provided device definitions (via Master Device List). Clicking on a network object in the diagram will give the user links to connect to these component devices via SSH or web client.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Security Zone
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Security zones are isolated paths through the network objects in an enclave. A ZoneViz diagram allows a user to trace the path of a security zone through the routers, switches, firewalls, etc. in a network. Security zones may also be connected to each other through a special connection such as an RAVPN. Security zones are indicated by VRF tags.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Getting Started
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] To set up ZoneViz, click on the ZoneViz menu item.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] You will see boxes representing the worlds in your setup (if you have set them up already). If you click on a world, its diagram will appear. If you have permissions to edit your setup, a button will appear at the top with the label, "Edit Diagram". The rest of this document will explain the Edit Diagram page, which you can see by clicking on the button.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] At the top will be two buttons, "Create World" and "View Diagram." Below that you will see a list of worlds that have already been created, if there are any. The first world will be expanded by default, so you can see its contents; the others will be collapsed, showing just the name and the buttons for actions you can perform. The buttons will be disabled on the other worlds; you can only click on them for the active world. Worlds can be re-ordered by dragging and dropping one into a new position. (Note that dragging is disabled while there is another drop currently in process.)
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] If you click on a collapsed world, it will expand and the previously expanded world (if any) will collapse. This collapsible list of worlds and enclaves is called the tree view and it is where you will select components to add and edit, and it will also give you an idea of the objects at your disposal. Most of your add and edit actions will be performed in a "drawer" on the right side of the screen, which will open when you click on an add or edit button.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] An expanded world will show a list of special connections at the top, followed by a list of enclaves.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Special connections are those other than the normal flow of networking along a Security Zone through network objects. There are three types:
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Filters are connections to the internet. They flow from and to a single security zone and a single network object.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Inter-Enclave connections connect two enclaves. They will be visible in the diagram only when both enclaves are expanded.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] RAVPN s are connections between two security zones. They could be in the same enclave or different ones.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Below special connections is a list of enclaves. One of them is always designated a "starter enclave" and appears first, expanded. The others appear in alphabetical order beneath it, initially collapsed. You can expand any one of them by clicking in the box, or by clicking the edit enclave button (indicated by a pencil icon).
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create a World
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] To begin with, you will not have any worlds, so you need to click the "Create World" button at the top. This will open a drawer on the right side of the page where you can give your new world a name and a description . The "starter enclave" dropdown will be empty, since you don't have any enclaves yet, and can be used later when you edit a world and want to change the starter enclave.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] There are 2 types of worlds that can be created
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Simplified A diagram that show all network objects and security zones in the enclave.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Detailed You can show additional information such as: connection between parent enclave and a child enclave, special connections, inter-enclave relation.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create an Enclave
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Your newly-created world will appear on the left, expanded, although there is nothing in it yet. You can click on the "Create Special Connection" button at the top of the world, but you won't be able to create any until you have at least one enclave and something in it. Therefore, your next action will be to click the "Create Enclave" button.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The "Add/edit Enclave" drawer will open. The name of the enclosing world appears at the top of the drawer. The only things you can set for an enclave are the name and type . The type must be one of the options in the dropdown. Once you have created an enclave, if you go back to this form to edit it, you will see a checkbox with the label "Starter" to indicate whether this is the starter enclave for its world. The checkbox is disabled, because you cannot set that value from here. If you want to change the starter enclave, edit the parent world and select a different enclave from the dropdown. (You must always have one starter enclave. When you create the first enclave in a world, it will automatically be designated the starter.)
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Once you have your first enclave, you can populate it with Network Objects and Security Zones. You also have the option to "Clone Enclave." Cloning is an efficient way to take a standard enclave and reproduce it quickly when you have many similar enclaves to make. You can even clone an enclave into a different world.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create a Network Object
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] We recommend you create all the Network Objects first, because Security Zones will need to select the Network Objects in their path. To create a Network Object, click the "Create Network Object" button in the appropriate enclave. The "Add/edit Network Object" drawer will open, with the name of the enclave at the top. You must enter a name for your Network Object and select a type from the dropdown; all other fields are optional.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The “Inner Tag” and “Outer Tag” fields are only applicable if Q-in-Q tagging is being utilized. Ask your network admin if you’re unsure.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The "Outer Tag Aware?" checkbox indicates if this Network Object is able to track outer tags. If adjacent Network Objects both have this property, their boxes will be touching in the diagram; if not, there will be a space between them.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The "Inner Tag" and "Outer Tag" fields allow you to indicate what tags this object assigns to packets passing through.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] You may choose to give "switch"-type Network Objects generic names (they do not have to be unique). For this reason, switches will be shown in the tree view with their Outer Tag appended, so you can easily distinguish them from one another.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] "Component Devices" shows a list of physical devices, by IP address and hostname, that have been discovered by ITPIE or entered manually on the Network Data page (Devices tab). You may select none, one, or several to associate with this Network Object. If you don't see the device you want, you can add it on the Network Data → Devices tab and then return to this screen.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] You will not be able to click the save button until the required fields (name and type) have been completed.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Network Objects are orderable, but you will not see a sequence number in this form. Instead, Network Objects are put in the order they are created. If you want to rearrange them subsequently, you can simply drag and drop them in the tree view.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] "Filter" type objects are the exception (see below). They are listed at the top and are not draggable.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create a Security Zone
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Once you have your Network Objects set up, you can create the Security Zones and their paths. Click on "Create Security Zone" for the enclave and an "Add/edit Security Zone" drawer will open.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] As with other objects, you must enter a name and type .
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Security Zones also require a numeric VRF ID.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] You may optionally add an inner tag to the Security Zone.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Every Security Zone has its own color. (Network Objects will be assigned a color based on their type.) Click inside the "Color" box and use the color picker to find a color you like. After choosing a color, click outside of the box to close the color picker. We recommend giving each Security Zone within an enclave a unique and easily identifiable color to distinguish it from the others, which will make your diagram easier to read.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The "Path" control will be populated with Network Objects in this enclave. Select all the Network Objects that the Security Zone will pass through.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] You may not reorder Network Objects in this form. If you need to reorder them, drag and drop them in the tree view and they will be re-ordered in the form. If a Security Zone already has Network Objects in its path, and those Network Objects get re-ordered, they will be re-ordered in the path automatically; you do not need to go back into the form.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] This is only relevant to the simplified world. You can enter custom virtual router name and new VRF label at the point where security zone passes through a network object.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Like Network Objects, Security Zones are orderable via drag and drop. They will appear in the diagram (as well as in the tree view) in order from top to bottom.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The section is specifically important when adding or editing a security zone for rendering simplified world, a textbox has been added to the Path section which will allow you to enter value such as: port number or VLAN tag.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create a Special Connection
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Once you have one or more enclaves with Network Objects and Security Zones set up, you may want to add Special Connections for your world. To do this, click the "Create Special Connection" button, which will reveal an "Add/edit Special Connection" drawer on the right.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Let's consider the three types of Special Connections in turn:
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Filter
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] A filter connects a single Security Zone and Network Object to the outside world. Although there are separate "First Enclave" and "Second Enclave" dropdowns, you cannot set these to different values. When you set the "First Enclave" dropdown, it will automatically change the "Second Enclave" to the same value. If you change the "Second Enclave" dropdown, ZoneViz will give you an error and reset the dropdown to match the "First Enclave."
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The "First Network Object" will be the one in the regular flow of Security Zones in your network. The "Second Network Object" must be a "Filter" type and the dropdown will be restricted to this type. The filter will not touch any Security Zones directly and is outside the regular order of Network Objects. Therefore, all filters appear at the top of the list of Network Objects in the tree view, and they are not draggable. A filter will be drawn parallel with the First Network Object that it is connected to.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Filter connections always depart from and return to the same Security Zone. Whichever Security Zone you select for "First" will automatically be selected in "Second," and it will not be modifiable.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] The middle of the form contains boxes for "First" and "Second" Outer Tags and Connection Labels. The Connection Labels are applied to the filter Network Object (e.g., LAN and WAN). The Outer Tags, if populated, are switches that will be put between the First and Second Network Objects, outgoing and incoming.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Inter-Enclave
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] An Inter-Enclave connection, as the name says, allows you to connect two enclaves. You choose the Network Objects and Security Zones in either enclave, and the diagram will draw a connection between them if they are both expanded.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] RAVPN
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] A Remote Access VPN is similar to a Filter, except that, instead of connecting a Security Zone to the outside world, it connects a Security Zone to another Security Zone. This can be two Security Zones in the same enclave, or in different encaves.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] At any time while you are adding data, you can click on the "View Diagram" button at the top of the page to see your diagram. Keep in mind that the diagram depends on having at least three specific Network Objects: a firewall, a load balancer, and a router, in that order. If you don't have these three objects, or if they are in a different order, your diagram may not render correctly. Also, make sure you have chosen distinct colors for your Security Zones.
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Create a Simplified View
[ITPIE:OPS Documentation | ZoneViz | https://itpie-hostname/documentation/content/features/zoneviz.html] Select the "Simplified" type when you create a new world. Then, finish creating the world by adding all other Configurations like Enclaves, Special Connections, Network Objects, and Security Zones. The World will have the "(Simplified)" label appended to the end of its name.
