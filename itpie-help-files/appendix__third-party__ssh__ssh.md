[ITPIE:OPS Documentation | SSH | https://itpie-hostname/documentation/content/appendix/third-party/ssh/ssh.html] SSH
[ITPIE:OPS Documentation | SSH | https://itpie-hostname/documentation/content/appendix/third-party/ssh/ssh.html] In several contexts on the Search, Maps, Discovery, and Collection pages, users can open an ssh session from within ITPIE by right-clicking on a IP and selecting "Connect via SSH" on the context menu. To open ssh protocol links directly from our application e.g. ssh://10.10.10.10 you must first have a protocol handler set up in your local environment which instructs your machine to open the proper client, such as PuTTY or SecureCRT.
